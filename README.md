# Bankkonto JDBC

Eine einfache Java-Anwendung zur Verwaltung von Bankkonten.

Das Projekt dient zum Erlernen von: 

- Java
- Maven
- JDBC
- SQL
- H2-Datenbank
- Repository-Pattern
- automatisierten Tests mit JUnit

## Voraussetzungen

- Java 25
- Maven
- Visual Studio oder eine andere Java-IDE

## Projektstatus

Das Projekt befindet sich derzeit in Entwicklung.
